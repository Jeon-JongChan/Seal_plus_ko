# Seal Plus

Seal 기반 Android 미디어 다운로더 확장판.

[English](../README.md)

## Seal 원본 대비 변경 사항

| 기능 | 설명 |
| --- | --- |
| 플러그인 | 14개 기능 개별 활성화. 기본 비활성. 설정·기록 보존. |
| 소셜 미디어 | Instagram·TikTok 이미지·영상 및 혼합 게시글 선택 다운로드. |
| 목록 다운로드 | 계정·게시글 목록 조회. 개별·전체 다운로드. |
| 미디어 처리 | AV1 변환·컨테이너 선택·기존 파일 재사용. |
| 라이브러리 | 폴더·해상도별 분류. 이동한 파일과 게시글 연결. 다운로드 이력 5개씩 표시. |
| 대기열 | 게시글 묶음·정렬·선택 관리. 5개씩 추가 표시. |
| 입력·메뉴 | 통합 입력·메뉴 즐겨찾기·빠른 쿠키 선택. |
| AI 이미지 | 이미지 복원·확대. 공유 모델·상세 조정·비교·교체 또는 복제. |
| AI 동영상 | QuickSRNet Small 기본·간편 최대 Medium. 모델 공유·FPS 선택·RIFE Vulkan 보간. AV1 우선 저장·원본 코덱 유지 선택. |
| 자주 방문하는 계정 | 기본 정렬은 받은 게시글 수. 프로필·게시글 바로 열기. |
| 게시글 정보 | 프로필 사진·계정명·본문·태그 표시 선택. |
| 저장폴더 | 기존 폴더 등록·요청별 선택·퀵 폴더 전환. |
| 얼굴 분류 | YuNet·MediaPipe 판별. NOFACE 게시글 연결 유지·변경 작업 제외. |
| 공유 메뉴 | 빠른 다운로드만 기본 표시. 한 기능 선택 시 바로 실행. |
| 뷰어 | 전체 화면·핀치 확대·반투명 배율. 재생바·음량 분리. |
| 다운로드창 | 형식 선택 한 줄·링크 입력 두 줄. 재시도·쿠키·로그 보기 한 줄. |
| 쿠키 | 재시도 쿠키는 현재 요청에만 적용. |
| 공통 구조 | 파사드·팩토리·전략/어댑터·템플릿. 공통 기능은 항시 활성. |
| 임시 숨기기 | tmp 안에서 다운로드·대기열·기록 격리. 종료 시 통합 또는 폐기. 내부 저장소 폴더만 지원. |
